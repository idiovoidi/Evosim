# Product Overview

## Ecosystem Simulation - Web Edition

A browser-based ecosystem simulation featuring genetic evolution and emergent behaviors across multiple species and biomes.

### Core Features

- **Multi-species simulation**: Herbivores, predators, plants, fish, and birds with unique behaviors
- **Genetic evolution**: Traits mutate and evolve across generations with inheritance and crossover
- **Procedural terrain**: Multiple biomes (grassland, forest, water, mountain, etc.) generated with simplex noise
- **Real-time analytics**: Population tracking, statistics graphs, and ecosystem event detection
- **Interactive controls**: Entity inspection, camera controls, speed/quality adjustment
- **Persistence**: Save/load system with auto-save functionality
- **Adaptive quality**: Automatic performance optimization based on FPS

### Architecture Pattern

Entity-Component-System (ECS) architecture with specialized systems for behavior, movement, health, reproduction, and biome effects.

### Target Platform

Modern web browsers (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+) with HTML5 Canvas support.
