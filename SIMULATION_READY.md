## What You'll See

### Main Canvas (Left Side)
- 🐰 **Herbivores** (rabbits) - Eat plants, flee from predators
- 🦊 **Predators** (foxes) - Hunt herbivores
- 🌿 **Plants** (grass) - Grow and reproduce
- 🐟 **Fish** - Swim in water areas
- 🦅 **Birds** - Fly around the ecosystem

### Sidebar (Right Side)
- 📊 **Population Stats** - Real-time counts
- 📈 **History Graph** - Population over time
- 🎮 **Controls** - Pause, reset, save/load
- ⚡ **Speed Control** - Adjust simulation speed
- 🔍 **Zoom Control** - Zoom in/out

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| **Space** or **P** | Pause/Resume |
| **R** | Reset simulation |
| **Ctrl+S** | Save game |
| **H** | Show tutorial |
| **+** / **-** | Adjust speed |
