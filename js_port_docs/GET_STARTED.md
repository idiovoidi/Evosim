## 🐛 Troubleshooting

### Server Not Running?
```bash
npm run dev
```

### Port Already in Use?
Vite will automatically use another port (3001, 3002, etc.)
Check terminal output for the actual URL.

### Blank Screen?
1. Open DevTools (F12)
2. Check Console for errors
3. Refresh page (Ctrl+R)

### Performance Issues?
1. Close other browser tabs
2. Reduce zoom level
3. Lower simulation speed
4. Check FPS in sidebar
