# 🚀 Quick Start - Web Version

## Installation (One Time)

```bash
npm install
```

## Running the Simulation

```bash
npm run dev
```

Then open your browser to: **http://localhost:3000**

## What You'll See

### Main Canvas
- 🗺️ Procedurally generated terrain with multiple biomes
- 🐰 Herbivores grazing and fleeing
- 🦊 Predators hunting
- 🌿 Plants growing
- 🐟 Fish schooling in water
- 🦅 Birds soaring and hunting

### Sidebar (Right)
- **Population counts** for all 5 species
- **Statistics** (total entities, FPS, time)
- **Controls** (pause, reset, speed, zoom)
- **Entity inspector** (click any creature)

## Basic Controls

| Action | How To |
|--------|--------|
| **Inspect Entity** | Click on any creature |
| **Pause/Resume** | Click "Pause" button |
| **Reset World** | Click "Reset" button |
| **Change Speed** | Drag speed slider (0.1x - 5x) |
| **Zoom In/Out** | Drag zoom slider (0.5x - 3x) |

## What to Watch For

### 🎯 Interesting Behaviors

1. **Herbivores fleeing** when predators get close
2. **Fish schooling** together in water bodies
3. **Birds hunting** from above
4. **Plants reproducing** in fertile areas
5. **Predators stalking** their prey
6. **Reproduction** (watch for 💕 hearts)

### 📊 Population Dynamics

- **Early game**: Rapid growth and expansion
- **Mid game**: Competition and predation
- **Late game**: Balanced ecosystem or extinction events

### 🧬 Evolution

- Click entities to see their genetic traits
- Notice how traits vary between individuals
- Watch offspring inherit parent traits
- Observe natural selection in action

## Tips for Best Experience

1. **Start at 1x speed** to observe behaviors
2. **Speed up to 3-5x** to see evolution
3. **Click entities** to learn about them
4. **Reset** to try different terrain
5. **Zoom in** to see details

## Troubleshooting

### Nothing appears on screen
- Check browser console (F12) for errors
- Refresh the page
- Make sure npm install completed

### Simulation runs slowly
- Reduce speed slider
- Close other browser tabs
- Try a different browser (Chrome recommended)

### Entities die immediately
- This is normal! The ecosystem is harsh
- Some species may go extinct
- Click Reset to try again
